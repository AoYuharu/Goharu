# 坦克大战 - 焕新版

## 1. 项目概述
- **项目名称**: Tank Battle Remix
- **类型**: HTML5 Canvas 像素街机游戏
- **核心功能**: 经典FC坦克大战的全面升级版，更好的视觉效果、更丰富的玩法
- **目标用户**: 怀旧玩家、像素游戏爱好者

## 2. 视觉规格

### 画布设置
- 画布尺寸: 832 x 640 像素 (26列 x 20行, 32x32像素每格)
- 复古像素风格，image-rendering: pixelated
- 轻微屏幕震动效果（爆炸时）

### 坦克设计（像素艺术风格）
四种敌人类型各有独特外观:
- 普通型: 暗绿色基础款
- 快速型: 蓝色 + 红色条纹（速度感）
- 重装型: 红色 + 加粗炮管
- 装甲型: 灰色 + 双重装甲标识

### 地形元素
| 元素 | 颜色 | 特效 |
|------|------|------|
| 砖墙 | #C84C0C | 4帧破碎动画，碎片粒子 |
| 钢墙 | #B8B8B8 | 金属光泽，子弹击中火星 |
| 水域 | #0066CC | 波纹动画，子弹穿过 |
| 森林 | #228B22 | 树木剪影，子弹穿过 |
| 基地 | #FFD700 | 旗帜飘动动画 |
| 基地(受损) | #8B0000 | 破损旗帜 |

### 爆炸特效
- 8帧渐进爆炸动画（原来是6帧）
- 颜色序列: 白 → 黄 → 橙 → 红 → 暗红 → 灰 → 消失
- 尺寸: 小(16px) 中(32px) 大(64px)
- 碎片粒子飞溅效果

## 3. 道具系统

| 图标 | 名称 | 颜色 | 效果 | 持续 |
|------|------|------|------|------|
| ⭐ | 火力升级 | 金黄 | 子弹从1发→2发→3发 | 永久 |
| 💣 | 炸弹 | 红色 | 清屏所有敌人+100分/个 | 即时 |
| ❄️ | 冰冻 | 冰蓝 | 敌人停止移动 | 8秒 |
| 🛡️ | 护盾 | 金色 | 无敌保护 | 10秒 |
| ❤️ | 生命 | 红色 | +1生命 | 即时 |
| ⛏️ | 铁锹 | 棕色 | 砖墙变钢墙保护基地 | 15秒 |

### 道具生成
- 敌人死亡时15%概率掉落
- 空中漂浮动画
- 闪烁提示存在
- 5秒后自动消失

## 4. 敌人AI增强

### 行为模式
| 类型 | 行为描述 |
|------|----------|
| 普通 | 随机移动，40%概率追踪玩家 |
| 快速 | 主动绕后，遇到障碍随机转向 |
| 重装 | 直线推进，锁定玩家方向射击 |
| 装甲 | 巡逻模式，发现玩家后包围 |

### 射击策略
- 每种类型有不同射击冷却
- 快速型会预判玩家移动方向
- 重装型子弹更大(8px vs 6px)

## 5. 得分系统

### 基础分
- 普通敌人: 100分
- 快速敌人: 200分
- 重装敌人: 300分
- 装甲敌人: 400分

### 连击系统
- 3秒内击杀敌人形成连击
- 连击倍率: x1 → x2 → x3 → x4 (封顶)
- 显示连击数和分数飞出动画

### 特殊得分
- 清屏炸弹: 每个敌人+100分
- 冰冻击杀: 分数x2
- 无伤过关: 奖励1000分

## 6. 音效增强

| 事件 | 音效特点 |
|------|----------|
| 射击 | 不同武器不同音色 |
| 爆炸 | 距离感衰减 |
| 道具获取 | 上升音阶叮咚 |
| 连击 | 连击数越高音调越高 |
| 敌人出现 | 警报提示音 |
| 过关 | 凯旋进行曲 |

## 8. 控制方案

| 按键 | 功能 |
|------|------|
| W/↑ | 向上 |
| S/↓ | 向下 |
| A/← | 向左 |
| D/→ | 向右 |
| 空格 | 射击 |
| P | 暂停 |
| M | 静音 |
| R | 快速重开（游戏结束后）|

## 9. 游戏状态

| 状态 | 说明 |
|------|------|
| START | 标题画面，带动画 |
| PLAYING | 正常游戏 |
| PAUSED | 暂停菜单 |
| DYING | 玩家死亡（3-2-1倒计时）|
| LEVEL_CLEAR | 过关动画+得分统计 |
| GAME_OVER | 结束画面，最高分记录 |

## 10. 关卡设计

### 地形复杂度递增
- Level 1-3: 简单布局，砖墙为主
- Level 4-6: 加入钢墙和水道
- Level 7-10: 森林掩护，更多通道
- Level 11+: 复杂迷宫，防守型基地

### 敌人类型解锁
- Level 1-2: 只有普通型
- Level 3-4: 加入快速型
- Level 5-6: 加入重装型
- Level 7+: 四种全开

## 11. 技术实现

- HTML5 Canvas 2D
- Web Audio API 音效合成
- 60 FPS 游戏循环
- 粒子系统（碎片、水花、火花）
- 本地存储最高分
- 零外部依赖
